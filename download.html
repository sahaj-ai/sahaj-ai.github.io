Installation

Up and running in a minute

Step-by-step for both operating systems — pick the one you downloaded.

Windows install

  1. 1
    Double-click the .exe installer you just downloaded.
  2. 2
    If Windows shows a "Windows protected your PC" warning, click More info → Run anyway.
  3. 3
    Follow the setup wizard — accept the license, pick a folder, click Install.
  4. 4
    Open সহজ-Sahaj from the Start menu, paste your license key, and start typing.

Ubuntu install

  1. 1
    Download the .deb installer — one file works on Ubuntu 22.04, 24.04, and 26.04.
  2. 2
    Install the package. Pick whichever method you prefer: 🖱️ Easiest — using App Center Double-click the downloaded .deb file. It opens in Ubuntu Software (22.04) or App Center (24.04 and 26.04), showing the Sahaj icon and an Install button. Click it, enter your password when asked, and wait a few seconds. ⌨️ Terminal method Open a terminal and run:
    sudo apt install ./Sahaj-3.0.0-amd64.deb
    from the folder where you downloaded the file (usually ~/Downloads). Using apt rather than dpkg ensures any missing dependencies are installed automatically.
  3. 3
    Open সহজ-Sahaj from your Applications menu — it's now installed like any other app.
  4. 4
    Paste your license key on the first launch — you're ready to type.
